🤔 Making Decisions: If Statements

Just like in real life, programs need to make choices!

🌧️ Rainy season in Lagos... Should I carry an umbrella?

IF it's raining → Bring umbrella ☂️

ELSE → Leave it at home 🏠

⚖️ Comparison Operators

print(5 > 3) # greater than → True print(5 < 3) # less than → False print(5 == 5) # equal to → True print(5 != 3) # not equal → True print(5 >= 5) # greater or equal → True
⚠️ Watch out! = puts a value in a box. == asks "are these equal?"

Your First If Statement

weather = "rainy" if weather == "rainy": print("Bring an umbrella! ☂️") else: print("Enjoy the sunshine! ☀️")
Bring an umbrella! ☂️
📏 The indented (pushed-in) lines belong to the if. Python is strict about this!

Multiple Choices with elif

temperature = 28 if temperature > 35: print("Too hot! 🥵 Stay in the shade!") elif temperature > 22: print("Perfect weather! 😊") else: print("Cool day! 🧥 Maybe a light jacket!")
Perfect weather! 😊

🧠 Logical Operators: AND, OR, NOT

age = 12 has_ticket = True if age >= 10 and has_ticket: print("Welcome to the movie! 🎬") else: print("Sorry, not today! 😔")
🎯 Predict: What happens if age = 8? What if has_ticket = False? What if we change and to or?

🎯 range(3) means "do this 3 times". Change 3 to 100 — one tiny edit, 100 prints!

⏰ While Loops: Keep Going Until...

countdown = 5 while countdown > 0: print(f"{countdown}... 🚀") countdown = countdown - 1 print("Blast off! 🎆")
5... 🚀
4... 🚀
3... 🚀
2... 🚀
1... 🚀
Blast off! 🎆

♾️ Danger: The Infinite Loop!

countdown = 5 while countdown > 0: print(countdown) # oops... we forgot to change countdown!
5
5
5
5... (forever!!! 😱)
🆘 If your program runs forever, click in the terminal and press Ctrl + C to stop it!

🛑 break: The Emergency Exit

while True: answer = input("Say the magic word: ") if answer == "please": print("You may pass! 🏰") break print("Nope, try again! 😄")
