🤖 What is Programming?

Programming = giving a computer very exact instructions.

🍜 Imagine teaching a robot to make indomie:

"Boil water" ✅   "Add noodles" ✅   "Make it nice" ❌ (too vague!)

Computers do EXACTLY what you say — nothing more, nothing less!

🐍 Why Python?

  • Reads almost like English — great first language
  • Powers YouTube, Instagram, Spotify & NASA tools
  • Used for games, apps, robots, and AI
  • One of the most in-demand skills in the world
🎬 Fun fact: Python is named after a comedy show (Monty Python), not the snake!

📦 Variables: Boxes with Labels

A variable is a labeled box where we store information.

name = "Tunde" age = 12 print(name) print(age)
Tunde
12

🔄 Variables Can Change!

score = 0 print(score) score = score + 10 # scored a goal! ⚽ print(score)
0
10

🏷️ Data Types: Kinds of Information

name = "Zainab" # str (text in quotes) age = 13 # int (whole number) height = 1.5 # float (decimal number) likes_python = True # bool (True or False)
🧠 Text needs "quotes". Numbers don't. True/False start with a CAPITAL letter!

🎤 input(): Talk to Your Program

name = input("What is your name? ") print("Nice to meet you, " + name + "!")
What is your name? Chidi
Nice to meet you, Chidi!
⌨️ input() pauses and waits for the user to type something, then hands it to you!

✨ f-strings: The Easy Way to Mix Text

name = "Ada" age = 11 print(f"Hi {name}! Next year you'll be {age + 1}!")
Hi Ada! Next year you'll be 12!
🪄 Put an f before the quotes, then use {curly braces} to drop variables right in!

🔢 input() Always Gives Text!

age = input("How old are you? ") age = int(age) # convert text ➜ number print(f"In 10 years you'll be {age + 10}!")
How old are you? 12
In 10 years you'll be 22!
🔧 int() converts text to a whole number. Without it, "12" + 10 breaks!
