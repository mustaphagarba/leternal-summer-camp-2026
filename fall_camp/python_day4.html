🛠️ Installing VPython

1️⃣ Open a terminal in VS Code (Terminal → New Terminal)
2️⃣ Type: pip install vpython and press Enter
3️⃣ Wait for "Successfully installed vpython"
4️⃣ Raise your hand ✋ if you see any red error text
📦 pip is Python's "app store." VPython is a toolkit other people built so we can make 3D scenes with just a few lines!

🌐 What Is VPython?

A toolkit that lets Python draw real 3D objects — spheres, boxes, rings — and animate them.

Without it, Python just prints text.

With it, Python can build a whole solar system! 🪐

🎓 VPython was made for teaching physics — scientists and students use it to simulate planets, springs, and more.

🎉 Your First 3D Scene

from vpython import * sun = sphere()

Save it as main.py and press Run ▶️ — a browser tab opens by itself with a white ball floating in 3D!

🪟 That browser tab IS your 3D window. Python draws the scene, and your browser displays it.

🎮 Activity: Sun Designer

Radius: 2



sun = sphere(pos=vector(0, 0, 0), radius=2, color=color.yellow)
🌞 Real stars come in different colors too — hotter stars look blue-white, cooler ones look orange-red!

📐 3D Coordinates: x, y, z

sun = sphere(pos=vector(x, y, z))
➡️ x — left / right
⬆️ y — up / down
👁️ z — toward you / away from you
📍 vector(0, 0, 0) is the center of the whole scene — the perfect spot for our Sun!

☀️ Turning the Ball Into a Sun

from vpython import * scene.background = color.black sun = sphere( pos=vector(0, 0, 0), radius=2, color=color.yellow, emissive=True )
💡 emissive=True makes the sphere glow on its own, like a real star. The black background turns the scene into outer space!

🔁 The Render Loop

To make things move, a 3D program repeats these steps, over and over:

1. Change something 🔄 ➜ 2. Wait a moment ⏱️ ➜ 3. VPython redraws 🖌️ ↩️ repeat!
🎬 It's like a flipbook — each page is a tiny bit different, and flipping fast makes things MOVE!

🌟 The Pulsing Sun

growing = True while True: rate(60) # wait: at most 60 frames per second if growing: sun.radius = sun.radius + 0.01 else: sun.radius = sun.radius - 0.01 if sun.radius > 2.5: growing = False if sun.radius < 2: growing = True
🎯 Look closely — that's Day 2's while loop and if/else, now making a star breathe in and out!

👀 Watch It Pulse (Live Preview)

🎞️ This flat preview does the same thing your Python code will do — the radius grows, shrinks, grows, shrinks…

⏱️ Why rate(60)?

  • It limits the loop to at most 60 frames per second
  • Without it, the loop races as fast as the computer can go
  • A racing loop can freeze the browser tab 🥶
🚨 Rule of the camp: every VPython while loop needs a rate() line as its FIRST line inside the loop!

🏗️ Putting It All Together

from vpython import * scene.title = "Solar Voyager" scene.background = color.black sun = sphere(pos=vector(0, 0, 0), radius=2, color=color.yellow, emissive=True) growing = True while True: rate(60) if growing: sun.radius = sun.radius + 0.01 else: sun.radius = sun.radius - 0.01 if sun.radius > 2.5: growing = False if sun.radius < 2: growing = True

🐛 Common VPython Hiccups

  • "No module named vpython" → pip install didn't finish
  • Nothing happens → check for a new browser tab
  • Error on color → it's color.yellow, all lowercase!
  • Frozen tab → you forgot rate() inside the loop
  • Closing the tab doesn't stop Python → click the terminal and press Ctrl + C
🕵️ Read error messages bottom-to-top — the last line usually tells you exactly what's wrong!
