😩 The Problem With Separate Variables

planet1 = "Mercury" planet2 = "Venus" planet3 = "Earth" planet4 = "Mars" # ...and we still have 4 more planets to go?? 😱

There has to be a better way to store a whole solar system!

📋 Lists: One Box, Many Planets

planets = ["Mercury", "Venus", "Earth", "Mars"] print(planets)
['Mercury', 'Venus', 'Earth', 'Mars']
🚀 A list is like a rocket's cargo bay — one variable holding many things, in order!

🔢 Indexing: Grabbing One Planet

planets = ["Mercury", "Venus", "Earth", "Mars"] print(planets[0]) print(planets[2])
Mercury
Earth
[0]Mercury [1]Venus [2]Earth [3]Mars
😲 Python counts from 0! Mercury (the closest planet) sits at planets[0], not planets[1].

📏 len() and append()

planets = ["Mercury", "Venus", "Earth"] print(len(planets)) # how many so far? planets.append("Mars") # add to the end print(planets)
3
['Mercury', 'Venus', 'Earth', 'Mars']

🗑️ Removing a Planet: The Pluto Story

solar_system = ["Mercury", "Venus", "Earth", "Mars", "Jupiter", "Saturn", "Uranus", "Neptune", "Pluto"] solar_system.remove("Pluto") print(solar_system)
🪐 True story: in 2006, astronomers officially reclassified Pluto as a "dwarf planet" and removed it from the official planet list. Real science changes lists too!

🔄 Looping Through the Solar System

planets = ["Mercury", "Venus", "Earth"] for planet in planets: print(f"🪐 {planet} is orbiting the Sun!")
🪐 Mercury is orbiting the Sun!
🪐 Venus is orbiting the Sun!
🪐 Earth is orbiting the Sun!
🎯 This is the #1 most useful pattern in ALL of programming: "for each thing in my list, do something." Solar Voyager will use this exact pattern to place every planet!

🪐 Build: Planet Log

discovered = [] name = input("A planet you know: ") discovered.append(name) name = input("Another one: ") discovered.append(name) print("Planets you logged:") for planet in discovered: print(f"🪐 {planet}")

⚙️ Functions: Do It Once, Use It Forever

A function is a named, reusable block of instructions.

🛰️ Like a mission-control checklist — write it once, run it whenever you need it!

📝 Defining a Function

def launch_briefing(): print("All systems go! 🚀") launch_briefing() # calling it launch_briefing() # calling it again!
All systems go! 🚀
All systems go! 🚀
🔑 def means "define." The function only runs when you CALL it with ()!

📦 Parameters: Giving Functions Info

def describe_planet(name): print(f"Scanning {name}... 🔭") describe_planet("Mars") describe_planet("Jupiter")
Scanning Mars... 🔭
Scanning Jupiter... 🔭
🎯 name is a parameter — a blank the function fills in differently each time it's called!

↩️ return: Sending a Value Back

def km_to_light_minutes(km): return km / 18000000 earth_distance = 150000000 result = km_to_light_minutes(earth_distance) print(f"Sunlight takes about {result:.1f} minutes to reach here!")
Sunlight takes about 8.3 minutes to reach here!
📮 print() just SHOWS something. return HANDS a value back so you can use it later — like the real 8-minute sunlight delay!

📦📦 Multiple Parameters: Habitable Zone Function

def in_habitable_zone(distance, has_atmosphere): if distance < 250 and has_atmosphere: return True return False earth_ok = in_habitable_zone(150, True) print(earth_ok)
True
🌍 We built this exact check yesterday with if/and — now it's wrapped in a reusable function!

🌍 Build: Habitable Zone Function

def in_habitable_zone(distance, has_atmosphere): return distance < 250 and has_atmosphere for planet_distance in [58, 108, 150, 228]: ok = in_habitable_zone(planet_distance, True) print(f"Distance {planet_distance}: habitable? {ok}")
🔁 One function, called 4 times with different distances — no copy-pasting the if statement!

🤝 Combining Lists + Functions

def print_solar_system(names): for name in names: print(f"🪐 {name} confirmed in orbit") planets = ["Mercury", "Venus", "Earth", "Mars"] print_solar_system(planets)
🪐 Mercury confirmed in orbit
🪐 Venus confirmed in orbit
🪐 Earth confirmed in orbit
🪐 Mars confirmed in orbit
🎮 This is EXACTLY the pattern we'll use to build the whole 8-planet system starting Day 6!

📋 Deliverable: The Planet Database

names = ["Mercury", "Venus", "Earth", "Mars"] distances = [58, 108, 150, 228] # millions of km def report_planet(name, distance): print(f"🪐 {name}: {distance} million km from the Sun") for i in range(len(names)): report_planet(names[i], distances[i])
🎯 Your mission: two parallel lists AND a function used together — the exact pattern Solar Voyager will use to build the real solar system!
