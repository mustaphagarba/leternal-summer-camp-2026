😩 The Problem With Separate Variables

player1 = "Ada" player2 = "Bola" player3 = "Chidi" player4 = "Dayo" # ...what if we have 50 players?? 😱

There has to be a better way to store LOTS of things!

📋 Lists: One Box, Many Items

players = ["Ada", "Bola", "Chidi", "Dayo"] print(players)
['Ada', 'Bola', 'Chidi', 'Dayo']
🎒 A list is like a backpack — one variable holding many things, in order!

🔢 Indexing: Grabbing One Item

players = ["Ada", "Bola", "Chidi", "Dayo"] print(players[0]) print(players[2])
Ada
Chidi
[0]Ada [1]Bola [2]Chidi [3]Dayo
😲 Python counts from 0! The first item is players[0], not players[1].

🎮 Activity: Index Explorer

toppings = ["suya", "jollof", "puff puff", "chin chin"]

🔄 toppings[-1] means "the LAST item" — negative indexes count from the end!

📏 len() and append()

toppings = ["suya", "jollof"] print(len(toppings)) # how many items? toppings.append("chin chin") # add to the end print(toppings)
2
['suya', 'jollof', 'chin chin']

🗑️ Removing Items

toppings = ["suya", "jollof", "chin chin"] toppings.remove("jollof") print(toppings)
['suya', 'chin chin']
⚠️ remove() deletes the FIRST matching item. If it's not in the list, Python throws an error!

🔄 Looping Through a List

players = ["Ada", "Bola", "Chidi"] for player in players: print(f"Welcome, {player}!")
Welcome, Ada!
Welcome, Bola!
Welcome, Chidi!
🎯 This is the #1 most useful pattern in ALL of programming: "for each thing in my list, do something."

🎵 Build: Playlist Manager

playlist = [] song = input("Add a song: ") playlist.append(song) song = input("Add another song: ") playlist.append(song) print("Your playlist:") for song in playlist: print(f"🎶 {song}")
🎯 Try This: Turn the two adds into a loop that asks 5 times!

⚙️ Functions: Do It Once, Use It Forever

A function is a named, reusable block of instructions.

🎬 Like a recipe card — write it once, "cook" it whenever you need to!

📝 Defining a Function

def greet(): print("Welcome to the game! 🎮") greet() # calling it greet() # calling it again!
Welcome to the game! 🎮
Welcome to the game! 🎮
🔑 def means "define." The function only runs when you CALL it with ()!

📦 Parameters: Giving Functions Info

def greet(name): print(f"Welcome, {name}! 🎮") greet("Amina") greet("Tunde")
Welcome, Amina! 🎮
Welcome, Tunde! 🎮
🎯 name is a parameter — a blank the function fills in differently each time it's called!

↩️ return: Sending a Value Back

def add_goal(score): return score + 1 my_score = 0 my_score = add_goal(my_score) my_score = add_goal(my_score) print(my_score)
2
📮 print() just SHOWS something. return HANDS a value back so you can use it later!

🎮 Quiz: print() or return?

I want a function that gives back a doubled number so I can store it in a variable

📦📦 Multiple Parameters

def total_cost(price, quantity): return price * quantity suya_bill = total_cost(500, 6) print(f"Total: ₦{suya_bill}")
Total: ₦3000
🎯 Try This: Write a function is_high_score(score, record) that returns True if score beats record!

🏆 Build: High Score Tracker

def check_high_score(score, high_score): if score > high_score: return score return high_score high_score = 0 new_score = int(input("Your score: ")) high_score = check_high_score(new_score, high_score) print(f"High score is now {high_score}!")
🔁 Call this function every round, and high_score always stays up to date!

🤝 Combining Lists + Functions

def print_roster(names): for name in names: print(f"✅ {name} is present") classroom = ["Ada", "Bola", "Chidi", "Dayo"] print_roster(classroom)
✅ Ada is present
✅ Bola is present
✅ Chidi is present
✅ Dayo is present
🎮 This is EXACTLY the pattern we'll use to move a whole squad of enemies later this week!
