🛠️ Installing Pygame

1️⃣ Open a terminal in VS Code (Terminal → New Terminal)
2️⃣ Type: pip install pygame and press Enter
3️⃣ Wait for "Successfully installed pygame"
4️⃣ Raise your hand ✋ if you see any red error text
📦 pip is Python's "app store" — it downloads extra tools other people built for us to use!

🏛️ What Is Pygame?

A toolkit that lets Python open windows, draw shapes, and react to the keyboard.

Without pygame, Python just prints text.

With pygame, Python can make an actual GAME! 🕹️

🔁 The Game Loop

Every video game ever made repeats these 3 steps, forever, dozens of times per second:

1. Check Input 🎮 ➜ 2. Update 🔄 ➜ 3. Draw 🖌️ ↩️ (repeat!)
🎬 Minecraft, FIFA, Museum Invaders — they ALL run this exact loop, just with fancier graphics!

🪟 Opening a Window

import pygame pygame.init() screen = pygame.display.set_mode((800, 600)) pygame.display.set_caption("Museum Invaders")
📐 (800, 600) is the width and height in pixels. That's our whole gallery floor!

🔁 The Loop in Code

running = True while running: for event in pygame.event.get(): if event.type == pygame.QUIT: running = False # (update stuff will go here) # (draw stuff will go here) pygame.display.flip() # show the new frame pygame.quit()
🖼️ pygame.display.flip() is like flipping to a new page in a flipbook — it shows what we just drew!

🎨 Drawing Our Curator

screen.fill((10, 10, 30)) # background color pygame.draw.rect( screen, (255, 215, 0), # gold color (380, 550, 40, 40) # x, y, width, height ) pygame.display.flip()
🎨 Colors are (Red, Green, Blue) numbers from 0-255. (255, 215, 0) is gold!

🖌️ Why We Fill Every Frame

while running: ... screen.fill((10, 10, 30)) # erase the old frame! pygame.draw.rect(screen, gold, curator_rect) pygame.display.flip()
🧽 Without screen.fill() every loop, old drawings never get erased — you'd get a smeary trail!

⌨️ Reading the Keyboard

keys = pygame.key.get_pressed() if keys[pygame.K_LEFT]: x = x - 5 if keys[pygame.K_RIGHT]: x = x + 5
🕹️ We check this EVERY loop — that's why holding a key keeps moving the curator smoothly!

🏗️ Putting It All Together

import pygame pygame.init() screen = pygame.display.set_mode((800, 600)) x = 380 running = True while running: for event in pygame.event.get(): if event.type == pygame.QUIT: running = False keys = pygame.key.get_pressed() if keys[pygame.K_LEFT]: x -= 5 if keys[pygame.K_RIGHT]: x += 5 screen.fill((10, 10, 30)) pygame.draw.rect(screen, (255, 215, 0), (x, 550, 40, 40)) pygame.display.flip() pygame.quit()

🚧 Staying On Screen

if keys[pygame.K_LEFT] and x > 0: x -= 5 if keys[pygame.K_RIGHT] and x < 760: x += 5
🧱 Without this check, the curator could walk right off the edge of the gallery forever!

🐛 Common Pygame Hiccups

  • Window opens then instantly closes → you're missing the while loop
  • Nothing draws → forgot pygame.display.flip()
  • Smeary trails → forgot screen.fill() each loop
  • "pygame not found" → pip install pygame didn't finish
🕵️ Read error messages bottom-to-top — the last line usually tells you exactly what's wrong!
