🤔 One Enemy vs. Many Enemies

We could make 8 separate variables...

alien1 = Alien(50, 50) alien2 = Alien(100, 50) alien3 = Alien(150, 50) # ...5 more?? 😩

...or store them ALL in one list!

📄 File: alien.py

alien.py
import pygame class Alien: def __init__(self, x, y): self.x = x self.y = y def draw(self, screen): pygame.draw.rect( screen, (200, 60, 200), (self.x, self.y, 32, 32) )
🏛️ Sound familiar? It's almost identical to Player from yesterday — that's the point of classes!

👾 Creating a Whole Row

from alien import Alien aliens = [] for i in range(8): new_alien = Alien(50 + i * 80, 50) aliens.append(new_alien)
🔁 One loop builds 8 aliens, each 80 pixels further right than the last. No copy-pasting needed!

🎨 Drawing Every Alien

for alien in aliens: alien.draw(screen)

TWO lines. Doesn't matter if there are 8 aliens or 800 — this still works!

🎯 This "for each thing in my list, do something" pattern is the heart of today. You've used it since Day 3!

🚶 Formation Movement

Classic arcade enemies move together as ONE group:

  • March sideways, all together
  • Bounce off the screen edge
  • Drop down one row when they bounce

➡️⬅️ One Shared Direction

direction = 1 # 1 = moving right, -1 = moving left for alien in aliens: alien.x += direction * 2
🧠 We don't give each alien its OWN direction — we use ONE shared variable so they all move in sync!

🏓 Bouncing Off the Edge

hit_edge = False for alien in aliens: if alien.x <= 0 or alien.x >= 760: hit_edge = True if hit_edge: direction = direction * -1
🔍 We check ALL aliens first — if even ONE hits an edge, the whole squad turns around!

⬇️ Dropping Down a Row

if hit_edge: direction = direction * -1 for alien in aliens: alien.y += 20
😱 This is the classic arcade "getting closer" panic moment — a nod to Space Invaders, the game that started it all!

🏗️ Putting It Together

direction = 1 while running: ... hit_edge = False for alien in aliens: alien.x += direction * 2 if alien.x <= 0 or alien.x >= 760: hit_edge = True if hit_edge: direction *= -1 for alien in aliens: alien.y += 20 for alien in aliens: alien.draw(screen)

🗂️ Our Project Now Has 3 Files

🐛 Common Squad Bugs

  • Aliens overlap → check your spacing math (i * 80)
  • Squad doesn't turn around → hit_edge never gets checked properly
  • Only ONE alien moves → the += is outside the for loop!
🕵️ If something is "supposed to happen to everyone" but only happens once, check your indentation — is it really inside the loop?
