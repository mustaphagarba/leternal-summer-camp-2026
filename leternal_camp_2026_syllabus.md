# Leternal Systems Programming Summer Camp 2026

**Format:** 2 weeks · 4 days per week (8 days total) · 3–4 hours per day
**Audience:** Preteens and young teens (ages ~10–15), no prior experience assumed
**Tracks (run in parallel):** 🐍 Python Track · 🌐 HTML/CSS Track
**Requirements:** One laptop per student (or per pair), instructor projector, offline installers for Python 3 and VS Code prepared in advance (recommended — don't rely on venue internet)

---

## Daily Rhythm (both tracks)

| Time | Block |
|---|---|
| 0:00 – 0:15 | Arrival, warm-up question / recap quiz |
| 0:15 – 1:15 | Lesson Block 1 (slides + live coding along) |
| 1:15 – 1:30 | Break / snack |
| 1:30 – 2:30 | Lesson Block 2 (slides + guided activity) |
| 2:30 – 3:15 | Exercise / project time (worksheets, pair work) |
| 3:15 – 3:30 | Show & tell, wrap-up, sneak peek of tomorrow |

Instructors float during exercise time. Fast finishers get ⭐ bonus challenges on each worksheet.

## 🐍 Python Track

### Week 1 — Foundations

**Day 1 — Hello, Python! (Setup Day)**
- What is programming? What can Python do?
- Environment setup: install Python 3 + VS Code, run first script (IDLE as fallback)
- `print()`, comments, variables, basic data types (str, int, float, bool)
- `input()` and f-strings
- Mini-build: Name Badge Generator, Mad Libs
- *Deliverable: every student runs a program they wrote on their own machine*

**Day 2 — Decisions & Loops**
- Comparison operators, `if` / `elif` / `else`
- Logical operators: `and`, `or`, `not`
- `for` loops and `range()`, `while` loops, `break`
- Mini-builds: Movie Ticket Checker, Countdown Rocket, Star Pattern Maker
- *Deliverable: a working "Guess My Number" starter game*

**Day 3 — Lists & Dictionaries**
- Lists: creating, indexing, `append`, `remove`, `len`, looping through lists
- Dictionaries: keys and values, adding/updating, looping
- Mini-builds: Playlist Manager, Pet Profile, Class Register

**Day 4 — Functions + Week 1 Project**
- Defining functions, parameters, `return`, combining everything
- **Project: Quiz Game Show** (questions in a list of dicts, score tracking, functions for each round)
- End-of-week showcase: students demo their quiz to the room

### Week 2 — Building & Creating

**Day 5 — Drawing with Code (Turtle Graphics)**
- The `turtle` module: moving, turning, pen colors
- Loops revisited visually: squares, stars, spirals, colorful patterns
- Mini-build: Design Your Own Flag / Geometric Art

**Day 6 — Randomness & Games**
- The `random` module: `randint`, `choice`, `shuffle`
- Handling bad input gracefully (`try` / `except` light-touch intro)
- Builds: Rock-Paper-Scissors, Dice Battle, full Number Guessing Game with limited tries

**Day 7 — Final Project Build Day**
- Students choose one: Text Adventure Game · Arcade Quiz 2.0 · Turtle Art Gallery · own idea (instructor-approved)
- Planning worksheet → build with instructor support

**Day 8 — Polish + Demo Day**
- Morning: finish and test projects, add a title screen / instructions
- Afternoon: **Showcase** — each student presents; certificates awarded

## 🌐 HTML/CSS Track

### Week 1 — Building Pages

**Day 1 — Your First Web Page (Setup Day)**
- How the web works: browsers, HTML, what a website really is
- Environment setup: install VS Code + Live Server extension
- HTML skeleton: `<!DOCTYPE>`, `<html>`, `<head>`, `<body>`
- Headings, paragraphs, line breaks, comments
- Images and links
- *Deliverable: every student opens a page they built in their browser*

**Day 2 — Structure + First CSS**
- Lists (`<ul>`, `<ol>`), grouping with `<div>`, semantic tags (`header`, `main`, `footer`)
- What CSS is; the three ways to add it (we use a `style.css` file)
- Selectors (element, class), colors (names + hex), fonts, text styling
- Mini-build: style yesterday's page — colors, fonts, centered headings

**Day 3 — The Box Model**
- Every element is a box: padding, border, margin
- Backgrounds, rounded corners, box shadows
- Mini-build: profile cards and colorful buttons

**Day 4 — Layout + Week 1 Project**
- Flexbox basics: row vs column, centering, spacing
- **Project: "All About Me" page** — photo/avatar, favorites list, styled sections
- End-of-week showcase

### Week 2 — Making It Shine

**Day 5 — Style & Motion**
- Hover effects, transitions, cursor styles
- Google-fonts-style typography (bundled offline fonts if no internet)
- Mini-build: animated button collection, flip-style cards

**Day 6 — Multi-Page Sites & Navigation**
- Linking pages together, navigation bars, folder organization
- Simple responsive thinking: making pages look good on phones
- Mini-build: 2–3 page mini-site with a shared nav bar

**Day 7 — Final Project Build Day**
- Students choose one: Personal Website · Fan Site (team, game, artist) · Class Magazine Page · own idea
- Planning sketch on paper → build with instructor support

**Day 8 — Polish + Demo Day**
- Morning: finish, test on different screen sizes, fix broken links/images
- Afternoon: **Showcase** — sites presented on the projector; certificates awarded

## Instructor Notes

- **Day 1 buffer:** Assume setup eats 60–90 minutes. The Day 1 decks are intentionally lighter so content still fits even if installs run long. Have installers on USB drives.
- **Pairing:** If machines are short, pair students and swap "driver/navigator" every 20 minutes.
- **Assessment is informal:** recap quizzes each morning + worksheet completion. The real assessment is Demo Day.
- **Cross-track moment (optional):** On Day 8, run a joint showcase so Python and Web students see each other's work.
